# AI Reel Studio

Русскоязычный веб-прототип для подготовки концепции коротких рекламных роликов.

## Что уже есть
- Загрузка видео-примера и фото/видео продукта в интерфейсе.
- Выбор бренда, формата и визуального стиля.
- Демо-сценарий по сценам.
- Черновик подписи и хештегов.
- Адаптивный интерфейс для телефона и компьютера.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages в настройках репозитория.

## Важно
Сейчас это frontend-прототип: он не анализирует содержимое видео с помощью ИИ, не рендерит итоговый MP4 и не публикует в Instagram. Для этих функций нужны AI API, серверная обработка/рендеринг видео и подключение Instagram через Meta OAuth с нужными разрешениями. Не размещайте API-ключи в клиентском коде.
