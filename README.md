# AI Reel Studio

Русскоязычный прототип для подготовки концепций коротких рекламных роликов.

## Уже сделано
- Адаптивный интерфейс для телефона и компьютера.
- Загрузка видео-примера и материалов продукта в интерфейсе.
- Настройки бренда, стиля и формата.
- Серверный endpoint `POST /api/generate-creative` для генерации сценария, подписи и хештегов через Gemini.
- API-ключ хранится на сервере в `GEMINI_API_KEY`, а не в браузере.

## Запуск локально
1. Установите Node.js.
2. В корне проекта выполните `npm install`.
3. Задайте переменную окружения `GEMINI_API_KEY` своим ключом Google AI Studio.
4. Запустите `npm start`.
5. Откройте `http://localhost:3000`.

Ключ API создаётся в Google AI Studio: https://aistudio.google.com/app/apikey

## Важные ограничения
- Чтобы генерация через Gemini работала, сервер нужно запустить и добавить действительный API-ключ в переменные окружения хостинга. Не публикуйте ключ в GitHub или в клиентском JavaScript.
- Пока не создаётся итоговый MP4: видео-рендеринг, обработка референс-видео и сборка сцен остаются следующим этапом.
- Автоматическая публикация в Instagram не подключена. Для неё нужны Meta OAuth, подходящий профессиональный Instagram-аккаунт и необходимые разрешения.
- Открытие `index.html` напрямую через двойной щелчок показывает интерфейс, но серверный AI endpoint так работать не будет.
